# `@pi/ai`

Streaming Anthropic Messages and OpenAI-compatible provider adapters used by
[piko](https://github.com/arunmenon/piko), including normalized tool calls,
retry handling, token usage, and model context-window metadata.

This package is currently pre-1.0, POSIX-only, and intentionally private pending
a project license/release decision. Its API may change between minor releases.
