# 0.2.0 evidence pack (historical captures)

These files are point-in-time captures from when the 0.2.0 release was
prepared. The tree has moved since (the test count and fixed-context figure
in these captures no longer describe HEAD), and the 0.2.0 tag was never cut;
the human release gates are still open. Treat everything here as a record of
that moment, not an attestation of the current tree. Regenerate the pack at
tag time.
