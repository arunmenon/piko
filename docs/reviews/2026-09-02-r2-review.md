## Findings

### 1. BLOCKER: a proposed bash call executes host code before validation or approval
Files: packages/core/src/agent.ts:1967, :2081, :2133, :2198; packages/core/src/tools/bash.ts:118.
The agent computes a git workspace digest based only on call.name === "bash", before
checking whether bash is configured, before the tool-call budget, before human
approval, and before cancellation. The digest runs real git processes with the
user's PATH and HOME; git status honors repository configuration such as
core.fsmonitor, which can execute another program.
Executed trigger: tools: [], an executable core.fsmonitor helper in the repository
configuration, a fake provider returning a call named bash. Observed: the helper
wrote its marker although there was no tool_start and bash was not available.
A second executed repro with a slow fake git and maxWallTimeMs: 20 took about
2,006 ms and a background child survived the probe. Every tool call is
fingerprinted before the tool budget is checked, so N bash calls in one response
multiply to N x 2 seconds.
Wrong outcome: the nominal file-only harness can execute host code and inspect
the parent's credentials before approval; the advertised wall deadline is bypassed.
Smallest fix: validate that the call names an enabled bash tool and check budget
and abort before any probe; never probe before approval; record the post-approval
fingerprint as pre-dispatch evidence; disable repository and global git execution
hooks and submodule traversal for the probe; use raw bytes for status output;
propagate the turn signal; terminate the whole process group; add marker,
rejection, unknown-tool, large-batch, deadline, and descendant-survival regressions.

### 2. MAJOR: extension pins hash one file but import another
Files: packages/cli/src/extensions.ts:69, :84; docs/adr/0012 addendum line 73.
readFileSync(resolved) is hashed, then the same pathname is imported later; nothing
ties the import to the hashed bytes. Executed: swapping the module between hash and
import journaled the benign digest and loaded the malicious export. Transitive
imports are also unpinned. Smallest fix: import an immutable content-addressed
snapshot, or narrow the contract explicitly to the entry module.

### 3. MAJOR: expected_sha256 is not a compare-and-swap precondition
Files: packages/core/src/tools/write.ts:13, :46; filesystem.ts:212; ADR 0007 addendum line 64.
Reasoned: hash A accepted, another writer replaces A with B, piko renames C over B and
reports success. The ADR's "safely reissue" claim is false. Hashing uses an unbounded
synchronous readFileSync. Smallest fix: implement a serialized conditional replacement
or describe the hash honestly as a stale-at-check-time diagnostic; hash through a
bounded descriptor.

### 4. MAJOR: tail repair and its audit row are separate durability transactions
Files: packages/core/src/session.ts:1038, :1087, :1124; ADR 0015 addendum line 94.
Reasoned crash: repairAppendBoundary() truncates and fsyncs, process dies before the
later durableAppend(); the next open sees a valid journal and no journal_repaired row,
so the discarded bytes are permanently invisible. Contradicts "same batch and the same
fsync". Smallest fix: make repair and evidence one atomic durability operation.

### 5. MAJOR: the capabilities contract disappears on important JSON failure paths
Files: packages/cli/src/main.ts:481, :529, :1317, :1336; ADR 0010 addendum line 93.
Capabilities ride the first Agent.run() event, not an independent first row. Executed:
provider transport failure before the first event emits only run_error without
capabilities; a suspended session without a decision, same; PI_DEPTH=3 --json
--max-depth 2 exits 1 with zero stdout bytes (required by child-bounds.test.ts:68).
Smallest fix: emit a dedicated contract row after setup before iteration; define an
honest partial static form for pre-setup failures; route depth refusal through run_error.

### 6. MAJOR: most ADR 0022 acceptance tests do not exercise complete tool paths
Files: packages/core/tests/containment.test.ts:151, :189, :214, :254; evidence map line 3.
Only the map case calls the real tool end to end; read, write, edit, mkdir, temp,
rename, and cleanup drive the resolver or helper directly. Smallest fix: add
deterministic named swap barriers to the real implementation and drive all eight
attacks through Tool.execute(); keep the split tests as lower-level supplements.

### 7. MAJOR: compaction is not reliably cache-prefix compatible with thinking enabled
Files: packages/core/src/agent.ts:1608, :2961; ADR 0003 addendum line 65.
Executed request-shape comparison: normal request thinkingBudget 8192, maxTokens 9216;
summary request maxTokens 768, no thinking. Anthropic documents that changing thinking
parameters invalidates message caches and on some models system and tool caches.
Smallest fix: make the claim conditional on all cache-key fields matching, measure
actual cache-read usage, document the trade. Other compaction mechanics sound: both
providers map toolChoice none; an ignored prohibition is journaled, not executed; the
cap is checked before billing; the final request is remeasured.

### 8. MINOR: rehydrated file paths are prompt-injection-shaped text
File: packages/core/src/agent.ts:2842. A filename containing a newline and
instruction-like text is inserted verbatim. Smallest fix: JSON-encode inside a fenced
data block labelled untrusted. A fake project-instruction closing marker did not
escape the framing; it truncated the recovered AGENTS.md body instead.

### 9. MINOR: Anthropic cache eligibility diagnostics use incorrect model minimums
File: packages/ai/src/cache.ts:20, :38, :69. Assumes 1,024 for non-Haiku and 2,048 for
Haiku. Current values include Opus 5: 512; Opus 4.7: 2,048; Opus 4.5/4.6: 4,096;
Haiku 4.5: 4,096; Haiku 3.5: 2,048. The message states "will not cache" as definite.
Smallest fix: a versioned model table; unknown models say "minimum unknown".

### 10. MINOR: "run" to "turn" broke the eval fallback detector
Files: packages/cli/src/main.ts:541; eval/result.ts:136; eval/result.test.ts:58.
The CLI writes "turn incomplete:"; the evaluator matches only "^run incomplete:".
Executed: exit 0, verifier success, usage completed, stderr turn incomplete, result
{"pass":true,"reason":"completed"}. Smallest fix: recognize both; test with the
producer string.

### 11. MINOR: tiny spend stops print an impossible-looking all-zero explanation
File: packages/cli/src/render.ts:63. Reservation $0.00000002 and ceiling $0.00000001
render as $0.000000 each; large values switch to scientific notation. Core arithmetic
and JSON values correct. Smallest fix: adaptive significant precision preserving the
inequality.

### 12. MINOR: the protected-path policy creates Linux false refusals
File: packages/core/src/tools/filesystem.ts:42. Every segment is lowercased regardless
of filesystem semantics; .Git/notes.txt is refused on a case-sensitive filesystem.
Reads remain allowed; map skips dot entries already (map.ts:166). Smallest fix: base
case folding on the workspace filesystem, or document the conservative trade.

## Fifteen-item verdicts
1 protected paths: defective (case folding). 2 expected_sha256: defective (race,
unbounded hashing). 3 spend ceiling: defective (precision). 4 turn wording: defective
(eval consumer). 5 capabilities row: defective (failure paths). 6 flail guard: sound.
7 child bounds: defective (JSON refusal; malformed-depth handling inconsistent at the
library boundary). 8 extension pins: defective. 9 journal repair row: defective.
10 workspace digest: defective. 11 replay conformance: sound (example-based).
12 two-number gate: sound. 13 cache measurement: defective. 14 compaction: defective
(thinking; path encoding). 15 containment tests: untested (seven not end to end).

## Regressions since 0b69794
- Internal eval no longer recognizes the CLI's incomplete marker.
- A missing, rejected, or not-yet-approved bash call now runs git helper code.
- Every proposed bash call can add up to two seconds before the tool budget applies.
- .Git, .Agent and similar names on case-sensitive filesystems are newly refused.
- Eight identical successful commands now stop the turn (intentional, documented).
- New lifecycle rows make journals unreadable by older strict readers (admitted in 0012).

## Minimum patch set for R2 closure
1. Eliminate pre-policy git execution; make the digest deadline and process-tree safe.
2. Import extensions from immutable verified snapshots, or narrow the provenance contract.
3. Fix or explicitly downgrade expected_sha256 from a CAS guarantee; bound hashing.
4. Make repair plus journal_repaired evidence one atomic durability operation.
5. Emit JSON contract and error rows independently of Agent events, including depth and suspension paths.
6. Convert ADR 0022 tests into true end-to-end tool attacks.
7. Qualify and test cache reuse with thinking; make cache minima model-aware.
8. Encode rehydrated paths as untrusted data.
9. Repair the eval marker, spend formatting, and protected-path portability.
10. Correct the six overclaims and add each executed reproduction as a regression test.
